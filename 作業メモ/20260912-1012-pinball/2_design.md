# 実装方針・影響範囲

## 画面レイアウト

800×600のうち、中央に縦長のテーブルを配置し、左右の余白は装飾（ネオン枠）と
HUDに使う。上部に薄いHUD帯（スコア・ハイスコア・残ボール）を置く。

```
PINBALL_TABLE_X = 210          # テーブル左端
PINBALL_TABLE_Y = 80           # テーブル上端
PINBALL_TABLE_W = 380
PINBALL_TABLE_H = 500          # テーブル下端 = 580
PINBALL_LANE_W = 34            # 右端の発射レーン幅
```

プレイフィールド（発射レーンを除く実際にボールが転がる領域）の左右端：
`FIELD_LEFT = TABLE_X = 210`, `FIELD_RIGHT = TABLE_X + TABLE_W - LANE_W = 556`。

## ボール数とターン管理（★重要な設計判断）

「3球」「マルチボール」「クリアなしのスコアアタック」を両立させるため、以下のように
**「ターン」と「同時に場にあるボールの数」を分離**する。

- `current_ball_number`（1〜`PINBALL_START_BALLS`=3）：現在何球目のターンか
- `active_balls`：現在フィールド上にある `Ball` インスタンスのリスト
  （通常は1個、マルチボール中は複数）

ロジック：
1. ターン開始時、`active_balls = [新しいBall]`（発射レーンで待機、SPACEで発射）
2. マルチボール発生時は `active_balls` に2個追加（**ターンは消費しない**。
   実機のピンボールでも「複数個ロックしてから同時解放」ではなく、
   「その場でボールを追加投入する」簡易化）
3. ボールがドレインするたびに `active_balls` から除去
4. `active_balls` が空になったら、そのターンは終了：
   - `current_ball_number < PINBALL_START_BALLS` なら `current_ball_number += 1` して
     次のターンを開始（新しいボールを発射レーンにセット）
   - それ以外（3球目も終わった）なら Game Over

この方式なら、マルチボールで一時的にボールが増えても「残りターン数」は減らないため、
3球という総枠と矛盾しない。

## テーブル要素

### 壁（静的な線分の集合）
- 左右の縦壁（テーブル上部〜フリッパー手前まで）
- 上部は緩いカーブ（数本の短い線分で近似）
- 下部はフリッパーへ向けて内側に絞り込む「ファンネル」形状（左右各1〜2本の
  斜め線分）。フリッパー両先端の間（中央、幅約100px）だけが開口部＝ドレイン経路
- 発射レーン（右端の縦通路）と本体プレイフィールドを仕切る壁。上端だけ開口して
  ボールがレーンから盤面へ入れるようにする

### ポップバンパー（3個・円）
`PINBALL_BUMPER_SCORE = 100`。当たると固定速度で跳ね返り＋得点。
1.5秒以内に連続ヒットするとコンボ（+50点ずつ加算、上限あり）。
配置目安：プレイフィールド上部〜中央に三角形状に3個。

### スタンドターゲット（3本・A/B/C、小さい矩形）
`PINBALL_TARGET_SCORE = 200`。当たると点灯（そのターン中は点灯を維持、次のターンで
リセット）。3本すべて点灯した瞬間に **その場でマルチボール発生**
（`active_balls` に2個追加、`PINBALL_MULTIBALL_BONUS = 2000` 加算、点灯状態は
リセットして再度3本揃えれば同一ターン中でも再度発生し得る）。

### ランプ（2本・左右対称）
入口ゾーン（小さい矩形）にボールが入ったら捕捉し、対応する出口へワープさせて
盤面上部へ戻す（3D的なランプ形状は再現せず、"入口→出口のワープ"で簡略化する
自作シンプル物理の範囲）。通過ごとに `PINBALL_RAMP_SCORE = 150` ＋ ランプごとの
コンボカウンタ+1。カウンタが `PINBALL_RAMP_JACKPOT_COUNT = 5` の倍数に達するたびに
`PINBALL_RAMP_JACKPOT_BONUS = 3000` を加算（カウンタはリセットせず伸ばし続け、
5の倍数ごとに繰り返しジャックポット）。

### ループレーン（1本）
右上を回り込む1本の曲線的な通路。ランプと同じ「入口→出口ワープ」方式で実装し、
通過ごとに `PINBALL_LOOP_SCORE = 300` を加算。

## ボール物理

```
PINBALL_GRAVITY = 900        # px/s^2
PINBALL_MAX_SPEED = 900      # px/s（上限、貫通対策）
PINBALL_WALL_RESTITUTION = 0.85
PINBALL_SUBSTEPS = 4          # 1フレームを分割して積分・当たり判定（貫通対策）
```

- 毎フレーム、`dt` を `PINBALL_SUBSTEPS` 分割して重力適用→移動→当たり判定を
  繰り返す（高速時の壁すり抜け対策。物理エンジンは使わず自前のサブステップ法）
- 壁・ファンネル：円と線分の反射（速度を法線に対して反射 ×
  `PINBALL_WALL_RESTITUTION`）
- バンパー：円と円の反射＋固定キック速度（`PINBALL_BUMPER_KICK = 380`）
- スタンドターゲット：円と矩形（近似的に線分扱い）の反射、控えめな反発係数
  （キックなし、`PINBALL_WALL_RESTITUTION` と同程度）
- ドレイン判定：ボール中心が `TABLE_Y + TABLE_H`（テーブル下端）を超えたら除去
  （壁のファンネル形状により、フリッパーで打ち返せなかった場合のみここに到達する）

## フリッパー

```
PINBALL_FLIPPER_LENGTH = 78
PINBALL_FLIPPER_REST_ANGLE = 35   # 度。外側下向き
PINBALL_FLIPPER_UP_ANGLE = -35    # 度。内側上向き（回転後）
PINBALL_FLIPPER_ANGULAR_SPEED = 1400  # 度/秒。素早く振り上げる
```

- 左右のフリッパーはピボット（回転軸）＋現在角度で表現。キー入力中は
  `UP_ANGLE` へ、離すと `REST_ANGLE` へ、`ANGULAR_SPEED` で毎フレーム回転させる
- 当たり判定：ボール（円）とフリッパー（線分＋太さ）の距離判定
- 反応：フリッパーが「振り上げ中（現在のフレームで REST→UP 方向に回転中）」に
  接触した場合は強いキック（固定速度 `PINBALL_FLIPPER_KICK = 620` を、
  ボールからピボットを結ぶ方向の外向き＋やや上向きに加える）。フリッパーが
  静止中（既にUP角度で止まっている、または REST で止まっている）に接触した
  場合は通常の反射（`PINBALL_WALL_RESTITUTION` 相当）のみ
- 操作：左矢印/Z＝左フリッパー、右矢印/X＝右フリッパー、スペース＝発射
  （発射レーン待機中のみ有効）

## 発射（プランジャー）

固定速度で打ち出す簡易方式（可変パワーのチャージは今回スコープ外、
`設計/known-issues.md` に将来検討として記録する）。

```
PINBALL_LAUNCH_SPEED = 620    # px/s（発射レーンから盤面上部へ直進）
```

## シーン状態機械（`pinball_scene.py`）

```
intro → launch（発射レーン待機、SPACEで発射） → play（自由に転動・フリッパー操作）
      → （active_balls が空になったら）
          ├─ current_ball_number < START_BALLS → launch（次のターン）
          └─ それ以外 → game_over
```

- `intro` は他ゲーム同様、開始演出＋任意キーでスキップ
- `play` 中にマルチボールが発生しても状態は `play` のまま（`active_balls` が
  増えるだけ）
- Game Over 遷移時はスコアを引き継ぐ（他ゲームと同じ `request_scene("game_over",
  score=...)`）。Clear シーンへの遷移は無し

## HUD

- 左上：`SCORE` / `HIGH`
- 右上：`BALL n/3`
- テーブル脇（左右の余白）に、スタンドターゲット A/B/C の点灯状態とランプの
  コンボカウンタを小さく表示（マルチボールに向けた進捗が見えるように）

## SE（`synth_audio.py` に追加）

`flipper`（フリッパー作動）, `bumper`（バンパー命中）, `target`（ターゲット命中）,
`ramp`（ランプ通過）, `loop`（ループ通過）, `multiball`（マルチボール開始）,
`jackpot`（ジャックポット獲得）, `launch`（発射）, `drain`（ドレイン）。
いずれも短い合成音（他ゲームの `_build_all` recipes と同じ形式）。

## ファイル構成

```
src/game_objects/pinball/
├── __init__.py
├── physics.py    # 円×線分・円×円の反射など、共通の物理ヘルパー関数
├── ball.py       # Ball（位置・速度・半径、update: 重力+サブステップ積分）
├── flipper.py    # Flipper（ピボット・角度・当たり判定・描画）
└── table.py      # 壁・バンパー・ターゲット・ランプ・ループレーン・発射レーン
                  #（静的ジオメトリの定義＋当たり判定の実行＋描画）
src/scenes/pinball_scene.py   # 状態機械・ターン/マルチボール管理・HUD・SE
```

`src/config.py` に `PINBALL_` 接頭辞で上記の定数一式を追加する。

## 影響範囲

- 新規ファイルが中心。既存ファイルへの変更は `config.py`（定数追加）、
  `main.py`（シーン登録）、`menu_scene.py`（`GAMES` の PINBALL のシーンキーを
  `None` → `"pinball"` に変更）、`synth_audio.py`（SE追加）のみ
- 他ゲームのロジック・描画には影響しない

## 動作確認方法

- `SDL_VIDEODRIVER=dummy` でのヘッドレス実行で、発射→バンパー/ターゲット/
  ランプ/ループへのヒット→スタンドターゲット3本点灯→マルチボール発生→
  複数ボールのドレイン→次ターン→3ターン終了後の Game Over 遷移まで、
  スクリプトでキー入力を送りつつ例外なく完走することを確認する
- `python src/main.py` でメニューから実際に起動し、目視でも確認する
