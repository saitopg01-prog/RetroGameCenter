# ピンボール（PINBALL）— 本格構成での新規実装

## 今回やること

レトロゲームセンターに新しいゲーム「ピンボール」を追加する。メニューには既に
「PINBALL」のカード（COMING SOON・サムネイル付き）があるが、シーン本体は未実装
のため、ゼロから実装する。

ユーザーとの合意により、最初からマルチボール・ランプ等を含む本格的な構成で
作る（最小構成からの段階拡張はしない）。

### テーブル構成

- **フリッパー**：左右2枚（下部固定）
- **ボール数**：3球。すべてドレイン（画面下端に落下）し尽くしたら Game Over。
  「クリア」の概念は無いスコアアタック型（テトリス・スネーク・ぷよぷよと同方針）
- **ポップバンパー**：3個。当たると跳ね返り＋得点、連続ヒットでコンボボーナス
- **スタンドターゲット**：3本（A/B/C）。3本すべて当てると「LOCK」状態になり、
  3球分ロックしたところで**マルチボール開始**
- **ランプ**：2本。通過ごとに得点＋ランプごとのコンボカウンタが増加、一定回数
  達成で「ジャックポット」ボーナス
- **ループレーン**：1本。外周を回って戻ってくる、スキルショット的な得点源
- **マルチボール中**：通常より高得点。複数のボールが同時に稼働し、すべて
  ドレインしたら通常モードに戻る
- **チルト（ナッジ）**：今回は実装しない（入力方式が煩雑になるため）

### 物理・操作

- 物理は他ゲームと同様の自作シンプル実装（円形ボール＋壁・バンパー・
  フリッパーとの反射計算）。専用の物理エンジンライブラリは追加しない
- 操作：左右矢印 or Z/X でフリッパー操作、スペースでプランジャー発射、
  ESC でメニューへ戻る（既存共通）
- 見た目のテーマは既存サムネイル（紫系のネオン調テーブル）を踏襲する

## 受け入れ条件

- [ ] フリッパー（左右）でボールを打ち返せる
- [ ] ポップバンパー・スタンドターゲット・ランプ・ループレーンに当たると
      それぞれ得点が入り、対応する演出（SE等）が発生する
- [ ] スタンドターゲット3本をすべて当てると LOCK 状態になり、3球ロックすると
      マルチボールが開始する
- [ ] マルチボール中は複数のボールが同時に物理演算・描画される
- [ ] ランプを一定回数通すとジャックポットボーナスが入る
- [ ] ボールがすべてドレインすると Game Over 画面に遷移する（スコア引き継ぎ）
- [ ] HUD（スコア・残ボール数・ハイスコア）が表示される
- [ ] 主要なアクション（フリッパー操作・バンパー/ターゲット/ランプヒット・
      マルチボール開始・ドレイン）に合成SEが鳴る
- [ ] `main.py` にシーン登録され、メニューの PINBALL カードから遊べる
      （`GAMES` のシーンキーを `None` から `"pinball"` に変更）
- [ ] `python src/main.py` で起動し、ヘッドレス自動プレイでボール発射〜
      各要素へのヒット〜マルチボール〜ドレイン〜Game Over までの一連の動作を
      例外なく確認できる

## やらないこと（スコープ外）

- チルト（ナッジ）機能
- 複数テーブル・ステージ選択
- スコアの永続保存（実行中のみ HIGH を保持、他ゲームと同方針）
- リプレイ（一定スコアでボール獲得）などの追加ルール
- 実際の物理エンジンライブラリ（Box2D等）の導入
