# イカジャンプ 設計方針

## 実装アプローチ

既存の `ice_climber`（縦スクロール・自前 stage クラス）や `snake` / `puyo_puyo` の
パターンにならい、`game_objects/ika_jump/` にゲームロジックを、
`scenes/ika_jump_scene.py` に `BaseScene` を継承したシーンを実装する。

### プレイヤー（イカ）

- 常に重力を受けて落下する。着地判定（足場の上面を落下中に通過）で
  自動的に `IKA_BOUNCE_POWER` の初速で跳ね上がる（入力不要のバウンド）。
- 左右キーで水平方向にのみ移動（空中でも操作可）。画面端は通り抜けず、
  画面内にクランプする（左右ループはやらないことに含める）。
- ジャンプ・移動速度は `ICE_JUMP_POWER` 等と同様に config.py で調整可能にする。

### 足場（プラットフォーム）

- 画面上方向に手続き的に生成する（固定リストではなく、カメラが進むたびに
  必要な分だけ新規生成し、画面外に出た古い足場は破棄する）。
- 3 種類：
  - 通常固定足場
  - 左右に往復する足場（ice の Topi のような単純な往復ロジック）
  - 一定時間着地すると崩れて消える足場（着地をトリガに崩壊タイマー開始）
- 高度が上がるほど、動く足場・崩れる足場の出現比率を上げて難易度を上げる。

### マグマ（追跡してくる床）

- ワールド座標で「マグマ上面の y」を管理し、時間経過とともに一定速度で
  上昇（y が減少）させる。高度が上がるほど上昇速度を少しずつ上げる。
- プレイヤーの矩形の下端がマグマ上面より下（世界座標で大きい）になったら
  即ゲームオーバー。
- ice_climber の「画面外へ落下したらミス」に相当する判定は、本作では
  マグマ接触判定がその役割を兼ねる（別途の落下ミス判定は設けない）。

### カメラ・スコア

- ice_climber と同様、プレイヤーを画面内の一定の高さ（アンカー比率）に
  保つようにカメラを追従させる。
- スコア = 到達した最高高度（ice_climber の highest_floor と同様の考え方）。
  HUD に現在スコアとハイスコア（クラス変数、実行中のみ保持）を表示。

## 影響範囲・変更ファイル

- `src/config.py` — `IKA_` 接頭辞の定数セクションを追加
  （プレイヤー寸法・速度・重力・バウンド初速、足場サイズ・間隔・出現比率、
  マグマの初期速度・加速、色定義）
- `src/game_objects/ika_jump/__init__.py` — 新規パッケージ
- `src/game_objects/ika_jump/player.py` — イカの物理・自動バウンド・移動
- `src/game_objects/ika_jump/stage.py` — 足場の生成・更新・種類ごとの挙動
- `src/scenes/ika_jump_scene.py` — `IkaJumpScene`（状態遷移・カメラ・
  マグマ・スコア・描画）
- `src/scenes/menu_thumbnails.py` — `_draw_ika_jump` を追加し
  `_DRAWERS` に登録
- `src/scenes/menu_scene.py` — `GAMES` リストに
  `("IKA JUMP", "ika_jump", "ika_jump")` を追加
- `src/main.py` — `IkaJumpScene` の import・登録
- ゲームオーバーは既存の `GameOverScene` をそのまま再利用（変更不要）

## 未確定事項（実装しながら調整）

- バウンド初速・重力・足場間隔の具体的な数値バランス（ice_climber と
  同様、まず妥当な初期値を置き、後で調整する）
- 動く足場・崩れる足場の出現比率カーブの具体的な式
