# イカジャンプ 追加

## 概要
「いかジャンプ」（左右キーで自動バウンドしながら足場を登り続ける国産フラッシュゲーム）を
元ネタとし、画面下からマグマが迫ってくる緊張感を加えたアレンジ版の新ゲーム
「イカジャンプ」をレトロゲームセンターに追加する。

## ゲームプレイ仕様
- プレイヤーキャラは着地すると自動でジャンプ（バウンド）する
- プレイヤー操作は左右キーのみ（空中での左右移動）
- 画面上部から新しい足場が次々と生成され、画面がスクロールして上へ登っていく
- 画面下端からマグマが常に迫り上がってくる。マグマに触れるとゲームオーバー
- 足場に着地できず落下してマグマに飲まれた場合もゲームオーバー
- 登った高さに応じてスコアが加算される（ハイスコア重視）
- 足場の種類（MVPに含める）
  - 通常の固定足場
  - 左右に動く足場
  - 一定時間で崩れて消える足場
- 時間経過（高度上昇）に応じてマグマの上昇速度が徐々に速くなる

## 画面・シーン
- 既存のシーン構成にならい `IkaJumpScene`（仮）を追加
- ゲームオーバー時は既存の `GameOverScene` を再利用し、最終スコアを表示

## 受け入れ条件
- [x] 左右キーでキャラを操作でき、着地すると自動でジャンプする
- [x] 足場が画面上部から継続的に生成され、画面が上方向にスクロールする
- [x] 画面下からマグマが迫り上がり、時間経過で速度が上昇する
- [x] マグマに触れる、または足場を外して落下しきるとゲームオーバーになる
- [x] 通常足場・動く足場・崩れる足場の3種類が出現する
- [x] 登った高さに応じたスコアが表示され、ゲームオーバー画面に最終スコアが表示される
- [x] メニュー画面からこのゲームを選択して開始できる

## やらないこと（スコープ外）
- アイテム・パワーアップ要素
- BGM・効果音の新規作成（既存の音声基盤を使う場合を除き、音源自体の用意は別作業とする）
- スコアのランキング保存（既存のJSON保存の仕組みへの統合は次フェーズで検討）
- モバイル向けタッチ操作対応
