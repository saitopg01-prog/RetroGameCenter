# アプリアイコン（ウィンドウ/タスクバー）の追加

## 今回やること

「レトロゲームセンター」アプリ自体のウィンドウ/タスクバーアイコンを新規作成し、
設定する。現状は `pygame.display.set_icon()` が呼ばれておらず、OS標準のデフォルト
アイコンのままになっている。

モチーフは**アーケード筐体のシルエット**（縦長の筐体・上部の画面・下部の
コントロールパネル）。画像生成AIツールが使えないため、ワギャンランドの
グラフィック刷新（[[project-sprite-asset-pipeline]]）と同じ方式で、コード内の
低解像度ピクセルキャンバスに `pygame.draw` で描いてから拡大し、PNGとして
書き出す。

## 受け入れ条件

- [x] `python src/main.py` でウィンドウを開いたとき、タスクバー/タイトルバーに
      アーケード筐体シルエットのアイコンが表示される
      （OS・環境によりタイトルバー表示は無い場合もあるが、タスクバーには表示される）
- [x] アイコン画像はコード生成スクリプトで再生成可能な状態になっている
      （生成済みPNGだけでなく生成元コードもコミットされる）
- [x] 既存のゲーム内サムネイル（`menu_thumbnails.py`）やメニュー画面の見た目・
      動作には変更がない
- [x] `python src/main.py` を実行し、アイコンが表示されること・他の動作に
      問題がないことを確認する

## やらないこと（スコープ外）

- 実行ファイル（.exe）化やその際の `.ico` 埋め込み対応（現状 `python src/main.py`
  で起動する運用のため対象外）
- メニュー画面内のゲームカードのサムネイル画像の変更
- 他ゲームのグラフィック変更

## 変更・追加ファイル（想定）

- 追加 `src/tools/generate_app_icon.py` — アイコン生成スクリプト
- 追加 `src/assets/app/icon.png` — 生成されたアイコン画像
- 変更 `src/main.py` — `pygame.display.set_icon()` の呼び出しを追加
