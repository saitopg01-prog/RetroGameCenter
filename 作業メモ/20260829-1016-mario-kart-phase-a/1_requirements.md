# マリオカート — フェーズA：Mode7風レンダリング＋運転＋タイム計測

## 今回やること

レトロゲームセンターに 6 本目のゲーム「マリオカート」を追加する。
本作は他ゲーム（ドンキーコング系・アイスクライマー・テトリス・スペースインベーダー）と
異なり **疑似3D（Mode7風の遠近表現）** のレースゲームであり、技術的難易度が高いため
3 フェーズに分けて進める。**今回はフェーズA**：CPU 対戦・アイテムなしの
「タイムアタック」として、疑似3Dレンダリングエンジンと運転の手触りを確立する。

- フェーズA（今回）：Mode7風レンダリング＋自機の運転＋3周タイム計測
- フェーズB（次回）：CPU カート 3 台を追加し、順位を競うレースにする
- フェーズC（次回）：アイテム（バナナ・こうら等）を追加する

原作コアの再現ポイント（フェーズA範囲）：

- コースをカート後方視点の疑似3D（Mode7風）で描画する。地平線・路面・縁石・芝生を
  遠近感を持って表現する。
- コース形状は **スタジアム型（角丸長方形）の周回コース 1 本**。
  中心線からの距離で「路面／縁石／芝生」を判定する。
- 自機カートは慣性のあるアーケード風の簡易物理で操作する：
  ↑ 加速、↓ ブレーキ・後退、← → ステアリング（旋回）。
- **コースアウト（芝生上）で速度が大きく低下する**（原作の減速ペナルティを再現）。
- スタート/フィニッシュラインを **3 周**するとレース終了。ラップタイム・合計タイムを計測する。
- HUD：ラップ数（1/3〜3/3）、経過タイム、ベストラップ（実行中のみ保持）。
- 3 周終了で Clear シーンへ（タイム表示）。CPU やミスの概念がないため
  GameOver シーンは使わない。ESC でいつでもメニューへ戻れる（既存共通）。

本作の他ゲームと統一された作りにする：`BaseScene` 継承、`config.py` に `MK_` 接頭辞で定数、
メニューには既存のサムネイル（`mario_kart`）をそのまま流用、クリアシーンは共通シーンを再利用。

## 技術決定：numpy の新規導入

Mode7風の疑似3D描画は毎フレーム画面の各走査線を遠近変形してコースをサンプリングする
処理が必要で、素の Python ループでは 60fps を維持できない。`numpy` でベクトル化して
実装する。現在の `requirements.txt`（pygame・pytmx のみ）に `numpy` を新規追加する。
実装後、`設計/architecture.md` に ARCH-005 として記録し、承認を得て反映する。

## 画面・操作

- 解像度 800×600（既存共通）。カート後方視点、画面下部にコース、上部に空。
- 操作：
  - ↑ : 加速
  - ↓ : ブレーキ・後退
  - ← → : ステアリング（旋回）
  - ESC : メニューへ戻る（既存共通）
