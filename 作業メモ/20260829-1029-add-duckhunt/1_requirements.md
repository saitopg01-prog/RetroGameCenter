# ダックハント風ガンシューティング — ゲーム追加

## 今回やること

レトロゲームセンターにガンシューティング（射的）ゲームを追加する。
今回は**ゲーム本体の実装からメニュー統合まで**を一括で行う（ぷよぷよと同方針）。

ダックハント（1984年 任天堂）のコアの再現ポイント：

- 画面に現れる複数種類の的（鳥・UFO など）をマウスカーソルで狙い、クリックで撃つ。
- 1ラウンドは弾数制限（例：3発）＋制限時間の両方で区切られる。
- ラウンドをクリアすると次のラウンドへ進み、的の速度・出現数が増えて難易度が上がる。
- 一定数以上撃ち逃すとゲームオーバー（原作の「ノルマ未達」に相当）。
- 高スコアへのやり込み・自己ベスト更新が主な楽しさの核。

本作は**マウス操作を新規に導入する**（他の全ゲームはキーボード操作のみ）。
`main.py` は既に全 pygame イベントをシーンへ転送しているため、
`handle_input` 内で `MOUSEBUTTONDOWN` / `MOUSEMOTION` を追加で処理するだけでよく、
共通基盤（`BaseScene` / `main.py` / `scene_manager.py`）の変更は不要な想定。

他ゲームと統一された作りにする：`BaseScene` 継承、`config.py` に `GUN_` 接頭辞で定数、
`synth_audio` の SE を可能な範囲で再利用、ゲームオーバーはテトリス・ぷよぷよと同じ
**シーン内オーバーレイ**方式（`R` でリスタート／`ESC` でメニュー）。

## 画面・操作

- 解像度 800×600（既存共通）。ドット絵背景（空・草原など）の上を複数の的が横切る。
- 操作：

  | 操作 | 動作 |
  |------|------|
  | マウス移動 | 照準（カーソル）を動かす |
  | 左クリック | 射撃（弾数を1消費） |
  | R | ゲームオーバー時にリスタート |
  | ESC | メニューへ戻る |

- **操作説明は画面内に常時掲載する**（他ゲーム同様、HUD 内に `CONTROLS` 表記）。
- 的の種類は複数（例：鳥・UFO・その他ミックス）。種類ごとに移動パターン・得点を変える。

## 受け入れ条件

- [x] 的がランダムな位置・タイミングで出現し、画面内を移動する（種類ごとに異なる軌道）
- [x] マウスカーソルで照準が表示され、左クリックした位置に弾が発射される
- [x] 的にカーソルが重なった状態でクリックすると命中、的が消えてスコア加算
- [x] 外れた場合は残弾が1消費される（残弾表示が減る）
- [x] 残弾が0になる、または制限時間が切れるとラウンド終了
- [x] ラウンド終了時、一定数以上の的を仕留めていればクリアとなり次ラウンドへ進む
      （的の出現数・速度が上がる）
- [x] ノルマ未達の場合はゲームオーバーになる
- [x] HUD にスコア・残弾・残り時間・ラウンド数が常時表示される
- [x] ゲームオーバー時に盤面上へオーバーレイ表示され、`R` でリスタートできる
- [x] 操作説明（マウス移動・クリック・リスタート・メニュー）が画面内に常時表示される
- [x] メニューに「DUCK HUNT」カードが追加され、専用サムネイルが表示され、
      ENTER で実際にプレイできる
- [x] SE が鳴る（発射・命中・外れ・ラウンドクリア・ゲームオーバー）
- [x] 実際に起動し、メニュー → プレイ → ラウンドクリア／ゲームオーバー →
      メニューの一連の流れを目視で確認する
      > 実行環境が非対話のサンドボックスで実ウィンドウを開けないため、
      > `main.py` と同じシーン登録・イベント処理を行うヘッドレス（SDL dummy
      > driver）スクリプトでメニュー／的の出現/命中/UFO・BIRD 両方の描画/
      > ラウンド失敗時のゲームオーバー演出をスクリーンショットで目視確認した。
      > 実ウィンドウでの動作確認はユーザー側で一度お願いしたい。

## やらないこと（スコープ外）

- 実際の光線銃（ライトガン）デバイス対応（マウスのみ）
- 2人交互プレイ（原作の2Pモード）
- 犬のキャラクター演出（命中/失敗時のリアクション演出）
- BGM（SE のみ。既存 `synth_audio` の方針を踏襲）
- スコアの永続保存・ランキング（他ゲームと同方針で実行中のみ保持）
- タッチ操作対応
