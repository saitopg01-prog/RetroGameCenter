# マリオカート — フェーズB＋C：CPU対戦＋アイテム

## 今回やること

フェーズA（Mode7風レンダリング＋運転＋タイム計測）に続き、残り2フェーズを
まとめて実装する（ユーザー指示により一括で進める）。

- フェーズB：CPU カート 3 台を追加し、順位を競うレースにする
- フェーズC：アイテム（バナナ・こうら）を追加する

### フェーズB：CPU対戦

- 自機 + CPU 3 台の計4台でレースする。
- CPU はコース中心線を追従する簡易オートパイロット（フェーズA検証で使った
  「進行方向の少し先の目標点を追いかける」ロジックを本実装に組み込む）で走行する。
  CPU ごとに速度・追従の癖を少し変え、順位が入れ替わる展開にする。
- 他カートは疑似3Dのビルボード（距離に応じて拡大縮小する平面スプライト）として描画する。
- 順位はコース中心を基準にした「進行角度の累積」で常時計算し、HUD に表示する
  （例: `3/4`）。
- レース終了条件は変更しない（自機が3周した時点で Clear シーンへ）。終了時に
  最終順位を表示する。

### フェーズC：アイテム

- コース上にアイテムボックスを 4 箇所程度設置。カートが通過すると
  バナナ／こうら のどちらかをランダムに1個所持する（同時に1個まで）。
  取得後、ボックスは一定時間で再出現する。
- バナナ：使用するとカートの後方に設置される。踏んだカート（自機・CPU問わず）は
  一定時間スピンアウト（操作不能・減速）する。
- こうら：使用するとカートの前方へ直進する弾になる。命中したカートは
  一定時間スピンアウトする。
- 自機はスペースキーで所持アイテムを使用する。CPU は取得後、ランダムな
  短い遅延で自動使用する。
- HUD に所持アイテムを表示する。

## 画面・操作（フェーズAからの追加分）

- スペース : 所持アイテムを使用（フェーズAでは未使用だったキー）

## 受け入れ条件

- [x] 自機 + CPU 3台でレースが成立し、他カートが距離に応じて拡大縮小する
      ビルボードとして描画される
- [x] CPU がコースに沿って自律走行する（コースアウトしても大きく破綻せず走行を続ける）
- [x] 順位（1〜4位）が常時計算され HUD に表示される
- [x] 自機が3周してレース終了すると、最終順位が Clear シーンに表示される
- [x] アイテムボックスを通過するとバナナ／こうらのいずれかを1個所持し、
      一定時間でボックスが再出現する
- [x] スペースキーでバナナを設置（カート後方）、こうらを発射（カート前方へ直進）できる
- [x] バナナ・こうらに自機/CPUが接触するとスピンアウト（一定時間操作不能）する
- [x] CPU も取得したアイテムを自動的に使用する
- [x] HUD に所持アイテムが表示される
- [x] `python src/main.py` で起動し、ヘッドレスで実挙動
      （CPU走行・順位計算・アイテム取得/使用/命中・レース終了）を確認する。
      自動操縦で3周完走・アイテム取得8回・約200fpsを確認。検証中に「スタート地点が
      フィニッシュラインに近すぎて1周目が実質ノーカウントで完了してしまう」バグを発見し、
      進行角度の累積が2π×0.85以上でなければ1周と認めないよう修正済み
