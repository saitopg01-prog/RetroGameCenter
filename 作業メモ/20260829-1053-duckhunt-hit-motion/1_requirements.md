# ダックハント — 命中モーション追加

## 今回やること

[20260829-1029-add-duckhunt](../20260829-1029-add-duckhunt/) で追加したダックハントで、
的に命中した瞬間が「即座に消える」だけで演出が無かったため、命中モーションを追加する。

ユーザー確認済みのイメージ：**シンプルな点滅削除＋スコアポップアップ**。

- 命中した的は即座には消えず、短時間（`GUN_HIT_FLASH_TIME`=0.35秒）点滅してから消える。
- 命中位置に `+得点`（例：`+100`）が表示され、少し上へ浮かびながら演出時間内に表示される。
- 点滅中はラウンドの終了判定（残弾0・時間切れ）を保留し、演出を最後まで見せる。

## 受け入れ条件

- [x] 命中した的が即座に消えず、点滅してから消える
- [x] 命中位置に得点（`+スコア`）がポップアップし、少し上へ浮かぶ
- [x] 点滅演出中（0.35秒）はラウンドが打ち切られない（残弾0・時間切れが同時に起きても
      演出が最後まで再生されてから次の的 or ラウンド終了処理に進む）
- [x] 画面上端付近で命中した場合でも、ポップアップが上部 HUD 帯の裏に隠れない
- [x] ヘッドレススクリプトで「命中直後は消えない → 演出時間経過後に消える」
      「点滅の非表示コマが実際に描画されない（体が消える）」を確認する

## やらないこと（スコープ外）

- 爆発・パーティクルなどのリッチな演出（今回はシンプルな点滅＋ポップアップのみ）
- UFO / BIRD で異なる命中演出（種類を問わず同じ演出にする）

## 変更ファイル

| 変更 | `src/game_objects/gun/target.py` | `hit` / `hit_timer` / `mark_hit()` / `is_hit_done()` を追加。`update()` は命中中は位置を止める |
| 変更 | `src/scenes/duck_hunt_scene.py` | 命中時に即消しせず `mark_hit()` を呼ぶよう変更。点滅描画・得点ポップアップ描画を追加。演出中はラウンド終了判定を保留 |

## 検証結果

ヘッドレス駆動スクリプトで以下を確認：

- 命中直後：`target.hit == True` かつ `current_target` はまだ同じインスタンスのまま
  （即消しされていない）
- 演出時間経過後：`current_target` が `None` になり次の的の抽選に進む
- 点滅の非表示コマ（`int(hit_timer*16) % 2 == 1`）で的の本体が描画されないこと
- 修正前は的が画面上端付近で命中すると `+得点` ポップアップが上部 HUD 帯の裏に隠れる
  表示崩れがあったため、`GUN_TOP_BAR_H` 基準で下限をクランプして修正済み
