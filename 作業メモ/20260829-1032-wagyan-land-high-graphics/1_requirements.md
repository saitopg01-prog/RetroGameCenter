# ワギャンランド ハイグラフィック化

## 今回やること

現在ワギャンランド（`src/game_objects/wagyan/`, `src/scenes/wagyan_land_scene.py`）は
プレイヤー・敵・地形・アイテム・ゴール・ボスをすべて `pygame.draw()` によるプリミティブ
図形（楕円・矩形・多角形）だけで描画している。これをドット絵スプライト画像に置き換え、
見た目のクオリティを大きく引き上げる。

画像生成AIツールが使えないため、実際のスプライト画像は Python コード内でピクセル
グリッド（色コードの2次元配列）として1ドットずつ定義し、生成スクリプトで PNG ファイル
として書き出す方式を取る。書き出した PNG はアセットとしてリポジトリに保存し、
実行時はそれを読み込んでスプライト描画する（生成元のコードも残し、後から調整・
再生成できるようにする）。

対象範囲は**全部**：

- プレイヤー（ワギャン）：立ち・歩行アニメ（2コマ）・ジャンプ・やられ演出
- 敵：通常・しびれ中（目を回す演出含む）
- 地形：地面ブロック、中州、浮遊足場（それぞれタイル状のドット絵）
- ワギャナイザー（拡声器アイテム）
- ゴール（旗）
- ボス戦の背景・Dr.デビル・対峙時のワギャン立ち絵

## 受け入れ条件

- [x] プレイヤー・敵・地形（地面/中州/浮遊足場）・ワギャナイザー・ゴール・ボス戦の
      Dr.デビル/ワギャンが、すべてプリミティブ図形描画ではなく PNG スプライト画像で
      描画される
- [x] スプライト画像は専用のアセットディレクトリに配置され、生成スクリプトで
      再生成可能な状態になっている（生成済み PNG だけでなく、生成元コードもコミット
      される）
- [x] プレイヤーの歩行・ジャンプ・やられ、敵のしびれ演出など、既存のアニメーション/
      状態表現がスプライト切り替えでも維持される（同等以上の表現力）
- [x] 既存の当たり判定・ゲームロジック（移動・ジャンプ・音波・しびれ・スコア等）に
      変更がない（見た目だけの変更）
- [x] `python src/main.py` で起動し、ワギャンランドを実プレイ/ヘッドレス自動プレイで
      確認して、グラフィックが差し替わっていること・動作に問題がないことを確認する
- [x] 解像度は既存のオブジェクトサイズ（例: プレイヤー 30×32、敵 30×26 等）を概ね
      踏襲し、他要素とのサイズバランスを崩さない
